上慶圍籬：AI 接手入口

這裡提供可重建程式的完整原始碼與維護規則，不包含客戶勘查紀錄。

  1. 先讀 AI_README.md 接手說明 與 修改規則
  2. 讀 檔案索引與 SHA-256
  3. 讀 全部原始碼 JSON；每筆含路徑、內容與雜湊
  4. 或從 GitHub 專案下載／修改完整程式

檢查：node --check app.js、node test.cjs。更新索引：node build-handoff.cjs。

重要規則：菱形網按公尺，不乘高度；示意圖即時更新，填妥後按「帶入圍籬 3D 工具」開啟完整出圖工作室；手機優先；舊 JSON 不丟失。
