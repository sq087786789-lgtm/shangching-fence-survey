## 使用方式
1. 手機直接開啟網站，可加入主畫面作為捷徑；目前需連網載入，並非離線 App。
2. 填寫案件資訊、逐段圍籬／門、長度、轉角、網規格、埋深。
3. 每段卡片最下方可按「在下方新增圍籬」，直接插入下一段並移到新段，不必滑回頂端；原有後續段落保留。新增圍籬帶入目前第一段圍籬的長度、高度、柱距、柱徑、線徑、網目、材質、橫桿、工法、埋深；轉角先設直行0°、備註留白，有差異再個別修改。修改第一段只影響之後新增的段落；若最前面是大門，會取第一個圍籬段；沒有圍籬則用預設規格。每個彎折新增一段；常用選單有左右15/30/45/60/90/120/135/150°與180°，也可輸入−180～180°小數角度。
4. 大門刪除後按「新增大門」，或在指定段後按「在此段後新增大門」；誤刪可按「復原刪除」。門加入後可編輯長度與方向。
5. 頁首「新設計」會先把目前案件保存為本機上一案，再建立一段圍籬的新案；「取回上一案」可交換恢復。上一案只保留一份，本機備份失敗就不清空舊案，重要案件請匯出 JSON。
6. 填妥後按「帶入圍籬 3D 工具」開啟完整工作室，自動帶入目前配置；可匯出含規格的客戶圖片（PNG）、規格表（CSV）、參照線稿（PNG／SVG）及可再編輯的設計JSON。工作室修改不回寫勘查表；「回勘查表」可繼續填寫。「取回帶入前的3D設計」可交換恢復工作室上一張圖。開啟網站即顯示示意圖，修改規格自動更新圖面，不必等套入。按「確認目前配置」標記已確認；後續修改會提醒重新確認。
7. 菱形網按長度公尺計價，不乘高度，不含門段。單價皆為可修改試算值。
8. 本機自動儲存；用完整 JSON 匯出／載入跨裝置移轉。請定期備份。

## 工作室快速操作
- 中間圖面太小時，按圖面上方「⛶ 放大圖面」暫時收起兩側設定，用大圖編輯；可按「返回一般畫面」或Esc回來。「看清本段」只放大目前選取段，置中則回到全案。大圖模式保留移動、編輯、轉向、縮放及復原／重做／刪除；調整右側規格時先返回一般畫面。
- 構件樣式新增「簡易圍籬（立柱＋菱形網）」，選取後隱藏所有橫管設定；立柱與網子照算，橫桿及管夾為零。要恢復橫桿，改選管夾式圍籬。
- 「管材與固定」第一項可選管材：鍍鋅管帶入柱厚1.8mm、錏管／亞管帶入1.4mm；厚度仍可手動調整，材質不跟著自訂厚度改變。立柱與門柱有各自的管徑選單，常用42.7、48.6、60.5、76.3、89.1mm，下方數字可自由修改；只修改選取段，不連動其他段。勘查表同步支援簡易樣式及獨立門柱規格。
- 線稿、客戶圖片與CSV分開顯示「圍籬長度(m)」和「大門淨開口(m)」，不再合併標題。立柱與門柱的外徑、厚度、管長也分列；舊案件的原始配置保留。
- 有一面圍籬已完成時，先選取該段，在右側「常用設定」勾「既有圍籬／門（不列本次施工）」，並填備註。圖面會以灰色呈現並標記不施工，客戶圖片與確認單保留位置及備註；材料CSV、數量與自動施工報價排除該段。勘查表的「施工範圍」有相同選項。這與仍須施工的「只裝圍網」不同；JSON備份會保留完整配置，方便再編輯。
- 客戶已有立柱時，按上方「＋只裝圍網」，或在本段「構件樣式」選「只裝圍網（既有立柱）」。可與一般圍籬、大門混合配置；只計菱形網公尺，不新增立柱、橫桿、基礎及管夾。既有柱以虛線作位置參照，柱距須依現場調整。勘查表的「施工項目」也有同一選項。
- 圖面上方「＋圍籬、＋大門、＋推拉門」新增構件；新增大門會直接選取新段並進入編輯。
- 推拉門可拖曳門片下方淡色「↔ 推拉門」鈕開關；編輯模式也能直接拖門片。右側可用滑桿或「關上／半開／全開」。只改開啟程度，門柱與門寬保持原位，整次拖曳可一次復原；A／B圈圈仍用來調整配置端點。滑輪、軌道與補強框為外觀示意，實際製作另行確認。
- 按橘色「✎ 編輯本段」後，在圖上選段或拖 A／B 端；橘色線及狀態列顯示目前選取段。右側「常用設定」可直接改長度、高度、柱距或門型。
- 管材、菱形網、輸出及配件數量分區收合，點標題展開；右側直接保留「刪除本段」。精確角度與座標輸入已移除，改用圖上端點及上方轉向操作。接點分開及方向箭頭在圖面上方「接點／方向進階」；手機可按「回到圖面」返回。
- 頁首可刪除本段、復原與重做；Delete／Ctrl+Z／Ctrl+Y亦可使用，輸入欄位內維持原本鍵盤操作。

## 專案內容
純 HTML、CSS、JavaScript，無建置依賴、無後端；Google 雲端功能使用瀏覽器公開識別設定。根目錄即網站。
