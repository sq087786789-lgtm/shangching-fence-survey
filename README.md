# 上慶企業社｜圍籬現場勘查與報價

手機使用網站：https://sq087786789-lgtm.github.io/shangching-fence-survey/

AI 接手入口：https://sq087786789-lgtm.github.io/shangching-fence-survey/ai.html

## 使用方式
1. 手機直接開啟網站，可加入主畫面作為捷徑；目前需連網載入，並非離線 App。
2. 填寫案件資訊、逐段圍籬／門、長度、轉角、網規格、埋深。
3. 每段卡片最下方可按「在下方新增圍籬」，直接插入下一段並移到新段，不必滑回頂端；原有後續段落保留。新增圍籬帶入目前第一段圍籬的長度、高度、柱距、柱徑、線徑、網目、材質、橫桿、工法、埋深；轉角先設直行0°、備註留白，有差異再個別修改。修改第一段只影響之後新增的段落；若最前面是大門，會取第一個圍籬段；沒有圍籬則用預設規格。每個彎折新增一段；常用選單有左右15/30/45/60/90/120/135/150°與180°，也可輸入−180～180°小數角度。
4. 大門刪除後按「新增大門」，或在指定段後按「在此段後新增大門」；誤刪可按「復原刪除」。門加入後可編輯長度與方向。
5. 頁首「新設計」會先把目前案件保存為本機上一案，再建立一段圍籬的新案；「取回上一案」可交換恢復。上一案只保留一份，本機備份失敗就不清空舊案，重要案件請匯出 JSON。
6. 填妥後按「帶入圍籬 3D 工具」開啟完整工作室，自動帶入目前配置；可匯出含規格的客戶圖片（PNG）、規格表（CSV）、參照線稿（PNG／SVG）及可再編輯的設計JSON。工作室修改不回寫勘查表；「回勘查表」可繼續填寫。「取回帶入前的3D設計」可交換恢復工作室上一張圖。開啟網站即顯示示意圖，修改規格自動更新圖面，不必等套入。按「確認目前配置」標記已確認；後續修改會提醒重新確認。
7. 菱形網按長度公尺計價，不乘高度，不含門段。單價皆為可修改試算值。
8. 本機自動儲存；用完整 JSON 匯出／載入跨裝置移轉。請定期備份。

## 專案內容
純 HTML、CSS、JavaScript，無建置依賴、無後端；Google 雲端功能使用瀏覽器公開識別設定。根目錄即網站。
- `index.html`：表單與版面。
- `app.js`：勘查資料、材料數量、試算、匯入匯出與即時預覽。
- `studio.html`：沿用原圍籬配置工作室的 Canvas 立體／平面圖與客戶圖片、規格、線稿輸出。
- `studio-bridge.js`：勘查表到完整工作室的本機一次性資料帶入。
- `style.css`：桌機與手機響應版面、手機快速切換。
- `AI_README.md`、`AGENTS.md`：給接手 AI 的規則與資料格式。
- `test.cjs`：可用 Node 執行的材料／資料相容性檢查。
- `build-handoff.cjs`：產生 AI 來源檔與 SHA-256 索引。

## 本機預覽與檢查
```sh
python -m http.server 8080
node --check app.js
node test.cjs
node build-handoff.cjs
```
開啟 http://localhost:8080 。請用 HTTP 同源開啟，勿直接雙擊 file://，否則跨頁套入可能無法運作。

## 資料與限制
客戶名稱、地址、電話和案件預設存在目前裝置／瀏覽器的 localStorage；只有手動按雲端儲存時，才會上傳至你選取的私人 Google Drive 資料夾。公開原始碼不包含實際勘查資料。清除瀏覽器資料、換手機或換網站網址不會帶走舊資料，須先 JSON 匯出再載入。
單段 0.5–5,000m、最多 200 段、單案總長最多 20,000m。埋深公分輸入、50cm 起；舊檔低於50保留並要求修正後套入。網目名稱為 2英吋、3英吋、4英吋、正2英吋；圖面毫米值只是近似示意，採購應以名稱與實際規格確認。
單獨埋入與混凝土埋入分別估價，怪手依全案台班數 × 台班單價 ＋ 進退場費計入報價，包含折讓與稅額計算；逐段怪手需求欄位已移除，統一在全案報價區填寫。半班可填0.5。舊資料新增費用預設0，原雜項保留，請檢查避免重複。主要材料未含斜撐、扣件、切料與耗損，非施工結構設計。不同規格暫共用同一類單價，正式報價前需覆核。

## 驗證狀態
數量、長路段、100段彎折、門段扣除、網長不隨高度改變及舊資料保留等檢查可執行 test.cjs。已做390px手機寬度檢查；尚未在實體 iPhone／Android 測試，下載與列印行為需實機覆核。

## 勘場照片
在「照片」區拍照或多選照片，點圖放大；可設定對應路段、備註、移除與復原。照片縮成最長1600px的JPEG，每張最多約350KB，每案20張；原圖請自行保留。照片影像存IndexedDB（sq-field-photos/images），表單與上一案只保存照片索引，預設不上傳；按雲端儲存才送到選取的 Google Drive 資料夾。匯出完整JSON含照片，可跨裝置載入；不含照片的3D設計檔與CSV僅供幾何／明細使用。匯入完整檔上限15MB。瀏覽器清除網站資料會連照片一起移除。已刪除路段的照片會標記待重新指定，復原路段可恢復關聯。

怪手只在報價區顯示與計價；各圍籬段不顯示怪手需求，也不顯示勾選段數或舊需求提醒。舊JSON的segments[].excavator保留相容，不參與費用計算。

新案件／新圍籬與3D工作室新增構件預設使用單獨埋入（direct），埋深50cm；後續圍籬沿用第一段設定。已儲存或匯入的案件保留原工法，不自動改寫。

新圍籬立柱外徑預設48.6mm，後續新增沿用第一段；門柱維持獨立規格（新門預設至少89.1mm）。已儲存／匯入案件保留原柱徑，不自動改寫。

## Google 雲端案件
在「雲端案件資料夾」依序登入 Google、選擇資料夾、儲存完整案件。每次會建立「案件名 · UTC時間」資料夾，完整 JSON 可還原表單、報價與照片；3D設計參數 JSON 可匯入工作室；勘場照片子資料夾另存縮圖及照片說明。載入清單顯示此網站成功儲存的版本；載入前先備份目前案為本機上一案。上傳中斷的資料夾不列入清單，舊版本不覆寫。若中斷可重新儲存新版本，未完成的資料夾可在 Drive 自行整理。

Google 登入目前使用測試模式，上慶帳號已列入測試使用者。其他員工須在 Cloud 目標對象加入測試帳號並取得資料夾權限；此版本尚未實作多人合併編輯。換裝置需重新登入並選擇相同資料夾。Google 登入短期逾時可重新連線，網站不保存權杖。雲端功能需網路，照片為本站縮圖，原圖仍需自行留存。

設定檔 drive-config.js 只有公開用戶端ID、專案號與受限瀏覽器API Key；不得放 client secret、access token、refresh token。Drive 與 Picker API 必須啟用。OAuth JavaScript 來源為 https://sq087786789-lgtm.github.io（不帶子路徑），Picker Key 限制此網站來源與 Google Picker API。範圍僅 drive.file，透過 Google Picker 明確選取案件根資料夾。複製專案到其他網域時必須自行設定 Google Cloud，不可直接沿用原網站的識別設定。

「選取雲端 JSON 載入」可從 Google Picker 明確選取先前手動上傳的完整勘查JSON，不必由此網站建立。選檔後只讀取該檔，驗證大小、內容與照片，先備份目前案才換案；不改寫雲端來源檔。

## 待確認草稿輸出
頁首「輸出確認單」產生當下案件快照。客戶版不含價格及內部自由備註、照片備註；需對外說明的文字填本次確認補充。內部版含報價與完整備註。兩版都有逐段規格、平面路線與照片，標記待確認，提供iframe預覽／列印另存PDF／自足HTML下載。來源confirmation.js build明確選取欄位，客戶檔不嵌入完整原始案件、報價或隱藏價格；獨立HTML含照片，可跨裝置開啟。補充欄只用於本次輸出，不回寫現場備註；修改表單後需重出。簽名欄僅核對用途，沒有電子簽章或線上送客戶功能。
