# 上慶企業社｜圍籬現場勘查與報價

手機使用網站：https://sq087786789-lgtm.github.io/shangching-fence-survey/

AI 接手入口：https://sq087786789-lgtm.github.io/shangching-fence-survey/ai.html

## 使用方式
1. 手機直接開啟網站，可加入主畫面作為捷徑；目前需連網載入，並非離線 App。
2. 填寫案件資訊、逐段圍籬／門、長度、轉角、網規格、埋深與怪手需求。
3. 每個彎折新增一段；方向可輸入任意角度，左轉為正、右轉為負。
4. 填寫過程不更動圖面。按「填寫完成，套入配置」才更新配置。
5. 菱形網按長度公尺計價，不乘高度，不含門段。單價皆為可修改試算值。
6. 本機自動儲存；用完整 JSON 匯出／載入跨裝置移轉。請定期備份。

## 專案內容
純 HTML、CSS、JavaScript，無建置依賴、無 API Key、無後端。根目錄即網站。
- `index.html`：表單與版面。
- `app.js`：勘查資料、材料數量、試算、匯入匯出與手動套入。
- `studio.html`：沿用原圍籬配置工作室的 Canvas 立體／平面圖。
- `style.css`：桌機與手機響應版面、手機快速切換。
- `AI_README.md`、`AGENTS.md`：給接手 AI 的規則與資料格式。
- `test.cjs`：可用 Node 執行的材料／資料相容性檢查。
- `build-handoff.cjs`：產生 AI 來源檔與 SHA-256 索引。

## 本機預覽與檢查
```sh
python -m http.server 8080
node --check app.js
node test.cjs
node build-handoff.cjs
```
開啟 http://localhost:8080 。請用 HTTP 同源開啟，勿直接雙擊 file://，否則跨頁套入可能無法運作。

## 網站部署
GitHub Pages 使用 main 分支的根目錄。提交修改後由 Pages 發布；Pages 發布成功前，不要宣稱已上線。也可把根目錄全部檔案上傳至一般靜態網站空間，保持相對路徑。
原先私人 Sites 測試網站是獨立部署；GitHub 的變更不會同步至私人 Sites。

## 資料與限制
客戶名稱、地址、電話和案件只存在目前裝置／瀏覽器的 localStorage。公開原始碼不包含實際勘查資料。清除瀏覽器資料、換手機或換網站網址不會帶走舊資料，須先 JSON 匯出再載入。
單段 0.5–5,000m、最多 200 段、單案總長最多 20,000m。埋深公分輸入、50cm 起；舊檔低於50保留並要求修正後套入。網目名稱為 2英吋、3英吋、4英吋、正2英吋；圖面毫米值只是近似示意，採購應以名稱與實際規格確認。
單獨埋入與混凝土埋入分別估價，怪手需求只記錄，費用填雜項。主要材料未含斜撐、扣件、切料與耗損，非施工結構設計。不同規格暫共用同一類單價，正式報價前需覆核。

## 驗證狀態
數量、長路段、100段彎折、門段扣除、網長不隨高度改變及舊資料保留等檢查可執行 test.cjs。已做390px手機寬度檢查；尚未在實體 iPhone／Android 測試，下載與列印行為需實機覆核。
